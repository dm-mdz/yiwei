一苇 Windows 版 0.1.0（键鼠共享：一套键盘鼠标控制 Mac 和这台 Windows，复制的文字、图片、100MB 以内的文件跟着指针过去，直接粘贴；指针离开后，那台电脑的剪贴板恢复成原来的；更大的文件用“发送文件”）

【装上】
1. 把 Yiwei.exe 放到一个固定的文件夹（比如 D:\一苇\），双击运行。没有安装界面，图标在任务栏右下角（可能收在“^”里面）。
2. 如果弹出“Windows 已保护你的电脑”（程序没有签名才这样）：点“更多信息”→“仍要运行”。
3. 第一次运行，防火墙会问是否允许 Yiwei 访问网络：勾上“专用网络”（家里的网络要是被标成“公用”，也勾上“公用网络”），点“允许”。

【连上 Mac】
4. Mac 上：点菜单栏的一苇，打开“键鼠共享”，按提示在“辅助功能”里把一苇打开。两台在同一个网络里，几秒后会互相发现。
5. 几台电脑是一“组”，一组共用一个校验码（面板点“展开”能看到）。要加入 Mac 那一组：在这台的面板里点“展开”，在发现的电脑旁点“加入”，最下面一行会变成输入框，填 Mac 面板里的校验码，回车；Mac 上会弹出“允许加入吗”，点允许。反过来从 Mac 加入这台也一样（这边点“是”）。加进去以后和那一组的每台电脑都自动连上，以后开机也不用再填。
6. 连上后这台会自动摆在 Mac 旁边。实际摆法不一样的话，在任意一边点“展开”，把卡片拖成桌上的样子，另一边会自动同步。
7. 鼠标推出那条边就到另一台上了；往回推就回来。回不来时连按三下 Esc。
9. 发文件：在小图上右键别的电脑，选“发送文件”或“发送文件夹”；也可以左键点一下那台电脑（出现蓝框，面板固定住不会自己收起），再把文件从资源管理器拖进面板，或者按 Ctrl+V 发送复制的文件；再点一下那台电脑取消选中；点托盘图标收起面板。收到的文件默认放在“下载\一苇”，右键自己这台（黄框）选“保存位置”可以改。收完托盘会弹通知，点一下打开所在文件夹。
8. 别的电脑的鼠标在这台上时，这台自己的鼠标键盘照常能用：两边的鼠标动的是同一个指针，谁动都行。想让这台的指针在别的电脑上时、那台自己的鼠标一动就切回这台：面板点“展开”，打开“鼠标被控切回”（每台各设各的，只管这台去控制别人的时候）。

【要知道的】
· 键位是原样对过去的：Mac 键盘的 ⌘ 在 Windows 上就是 Win 键，⌥ 是 Alt。所以在 Windows 上复制还是按 Control+C。
· 以管理员身份运行的窗口（比如任务管理器）里，从 Mac 过来的键鼠可能不听使唤，这是 Windows 的限制。
· 有好几块显示器时，按它们合起来的外框算边：外框内侧那几条边穿不过去。
· 锁屏时鼠标会自动回到这台电脑。
· 两台电脑上的一苇要是同一版。不一样时面板里会提示该更新哪一台。
· 面板里提示“没有响应”：多半是那台电脑的防火墙没放行一苇（专用、公用网络都要勾上）。
· 出问题时，Yiwei.exe 旁边的“一苇日志-电脑名.txt”记着发生了什么（不记复制的内容，也不记校验码）。
· 点任务栏右下角的一苇图标（没看到就点“^”）弹出面板，和 Mac 菜单栏里的一样：键鼠共享开关、电脑位置图；点“展开”可以拖位置、加入发现的电脑、手动添加；还有开机时自动启动、退出。右键位置图里别的电脑可以把它“请出这一组”（这一组随即换一个新校验码）；点校验码旁的“换一个”也可以换。手动添加时在输入框里填“地址 校验码”，中间空一格。
· 卸载：先在托盘菜单里“退出一苇”，删掉 Yiwei.exe，再删掉 %LOCALAPPDATA%\Yiwei 文件夹（里面是这台电脑的身份和所在的组）。
